# Languages (i18n)

The default language lives at the root (`/about/`); every other language
lives in its own folder (`/de/ueber-uns/`). One table links each page to its
translations, and everything else is built from it.

## Files

| File | What it holds |
| --- | --- |
| `src/i18n/config.ts` | The languages: label, flag, `htmlLang`, Open Graph locale, text direction |
| `src/i18n/routes.ts` | Every page and its URL in every language (`PAGES`) |
| `src/i18n/ui.ts` | Short interface words per language (nav, footer, buttons) |
| `src/views/*.astro` | Page bodies shared by all languages |
| `src/pages/` and `src/pages/<code>/` | One small file per page and language that renders a view |

From `PAGES` the template builds:

- the **language switcher** (`LangSwitcher.astro`): the current flag, every
  language inside, each linking to the same page in that language or to that
  language's home if the page is not translated;
- **hreflang** tags and `x-default` in every page head (`SEO.astro`);
- **sitemap** alternates (`astro.config.mjs`);
- **llms.txt**.

## Add a language (example: Spanish)

1. `src/i18n/config.ts`: add
   `es: { label: 'Español', flag: '🇪🇸', htmlLang: 'es', ogLocale: 'es_ES', dir: 'ltr' }`.
   Arabic or Hebrew: `dir: 'rtl'`.
2. `src/i18n/ui.ts`: add `const es: Dict = { ... }` with every key, and add
   it to `UI`. TypeScript tells you if a key is missing.
3. `src/i18n/routes.ts`: add `es: '/es/...'` to each page, with Spanish slugs
   (`/es/sobre-nosotros/`, `/es/contacto/`, `/es/privacidad/`, `/es/precios/`).
4. Create `src/pages/es/` with one file per page (copy `src/pages/de/` and
   change `lang="de"` to `lang="es"` and the copy).
5. `npm run build && npm run check`.

## Add a page in several languages

1. Add a row to `PAGES`: `calculator: { en: '/percentage-calculator/', de: '/de/prozentrechner/' }`.
2. Build the body once in `src/views/`, taking `lang` as a prop.
3. Add a page file per language that renders the view with `page="calculator"`.

A page can exist in fewer languages than the site: leave the missing
languages out of its row and the switcher sends them to their home page.

## Rules

- Research keywords **per country** before translating. The words people
  search are often not a literal translation.
- Translate the slug, title, description, H1 and FAQ, not just the body.
- Have a native speaker proofread before you promote a language.
- Do not auto-redirect visitors by browser language: Googlebot crawls from
  the US and would never see the other languages. Let the switcher do it.
- Prefer folders (`/de/`) over separate domains: one domain shares its
  authority with every language and is one site to maintain.
